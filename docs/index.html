Five jobs, and the code that does them

Each program reads one byte at a time, decides, and writes. No regular expressions, no library, nothing you cannot follow.

program 01

Strip the query string

Cut a URL at the ?, so the tracking parameters never reach the person you send it to.

program 02

Squeeze runs of spaces

A space is dropped when the byte before it was also a space. Tabs and newlines are left alone.

program 03

Wrap at 40 characters

A counter counts down and refills — the same three instructions however long the text is.

program 04 · 05

Strip the fragment · one line per sentence

Cut at the # as well as the ?, or break a paragraph at every full stop.

Why assembly, of all things

Because a clipboard filter is a place where you should be able to see exactly what happens to your text. Every program here is short enough to read on one screen, and the app shows you the bytes and the step count after every run.

  • Nothing leaves the tab. The text is read byte by byte by a machine in the page.
  • Every program is proved. Each ships examples, and the test suite runs them on the real machine — including the empty clipboard and a 120-character paragraph.
  • Built on the Loom. The machine is weft8.js from app-jacquard, byte for byte the same engine.
